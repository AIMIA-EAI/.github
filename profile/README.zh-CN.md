- **01 · 具身智能**：Agent 规划器 + Agent 原生动作器 / VLA，连接任务规划、动作执行与环境反馈。
- **02 · 多模态**：图像生成与编辑、视频生成、人体动作生成、视觉语言理解与视觉定位。
- **03 · AI4S**：蛋白质突变效应预测、结构与功能建模、分子生成与设计、病毒演化预测、医学影像分析。
